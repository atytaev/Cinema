# Moonlight

Moonlight — это веб-приложение на Python с использованием Django для управления кинотеатром. Приложение предоставляет функционал для работы с фильмами, сессиями, билетами и пользователями.

Основные возможности

 ### 1.  Управление фильмами:

* Просмотр списка фильмов.
* Фильтрация фильмов по названию, жанру и году выпуска.
* Детальный просмотр информации о фильме.

### 2. Управление сессиями:

* Просмотр расписания сеансов.
* Фильтрация сеансов по дате.
* Детальная информация о сессии.

### 3. Управление билетами:

* Бронирование мест на сеанс.
* Просмотр списка забронированных билетов.
* Отмена билета.
* Оплата билетов (демонстрационная).

### 4. Пользователи:

* Регистрация и авторизация.
* Управление своими билетами.

## Установка
### Предварительные требования

* Python 3.10+
* pip
* Git

### Шаги установки

1. Клонируйте репозиторий:

`git clone https://github.com/atytaev/Cinema.git`

`cd Cinema`

2. Создайте виртуальное окружение и активируйте его:

`python -m venv venv`

`source venv/bin/activate`  # или venv\Scripts\activate для Windows

3. Установите зависимости:

`pip install -r requirements.txt`

4. Выполните миграции базы данных:

`python manage.py migrate`

5. Создайте суперпользователя для доступа к административной панели:

`python manage.py createsuperuser`

6. Соберите статические файлы:

`python manage.py collectstatic`

7. Запустите локальный сервер разработки:

`python manage.py runserver`

Теперь приложение доступно по адресу http://127.0.0.1:8000/.

## Использование

### Основные URL

* Главная страница со списком фильмов: /
* Детальная информация о фильме: /film/<id>
* Список сеансов: /sessions/
* Бронирование билета: /tickets/book/<session_id>
* Личный кабинет пользователя: /user/tickets/

### Административная панель

Административная панель доступна по адресу /admin/. Используйте учетные данные суперпользователя для входа.

### Технологии

* Backend: Django
* Frontend: HTML, CSS (Django templates)
* База данных: PostgreSQL
* Управление зависимостями: pip
* Аутентификация: Django Authentication Framework
